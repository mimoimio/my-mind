The game should speak the player's language, using concepts and conventions they already understand
- **Application:** Using [[universally understood icons]] (a heart for health, a sword for attack). Physics should generally behave as expected unless magic is involved—heavy objects should fall faster, and fire should cause burns.
    
- **Game Dev Example:** If a player is navigating a tavern or tycoon interface, the currency should be something [[intuitive]] like "Coins" or "Gems," and the button to upgrade a table should look like an upward arrow or a hammer.

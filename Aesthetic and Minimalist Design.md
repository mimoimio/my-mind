Interfaces should not contain information that is irrelevant or rarely needed.

- **Application:** HUD (Heads-Up Display) clutter is a massive issue in game design. A clean, minimalist UI ensures the player is looking at the game world, not reading spreadsheets on the screen.
    
- **Game Dev Example:** Dynamically hiding UI elements when they aren't needed. For instance, hiding the health bar when the player is safely exploring a town, and only fading it in when combat initiates.
